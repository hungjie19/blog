# Blog Canonical Tags

這份檔案是 blog repo 的核心 taxonomy / preferred terms map，不是熱門詞排行榜，也不追求完整枚舉。

目前先只建立位置，不預填任何 canonical tag。具體 taxonomy 要等執行 blog tag audit、抽樣確認既有文章 tag 用法後再補，不由 skill 或初始架構憑空決定。

## Core Groups

待 blog tag audit 後補。
