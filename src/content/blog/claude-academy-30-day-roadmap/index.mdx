我每天都在用 Claude：用它協助工作、在 Claude Code 裡一起改 code，也會讓 Cowork 處理一些日常任務。最近為了規劃鐵人賽，我重新打開 Anthropic 的課程平台，卻發現它已經從 Skilljar 改版成了 Claude Academy，還多了繁體中文介面與新課程。

那一刻我突然覺得，自己好像一直在使用 Claude，卻沒有好好重新認識它。熟悉工具的操作，不代表真的理解它的能力邊界；更不代表知道官方希望使用者建立什麼樣的工作方法。

## 先認識 Claude Academy

[Claude Academy](https://academy.claude.com/zh-TW/courses) 是 Anthropic 的官方教學網站，提供課程、短篇教學與使用案例，從第一次和 Claude 對話，一路延伸到 Claude Cowork、Claude Code、MCP、AI Fluency，以及使用 API 開發應用程式。課程頁面也把內容整理成「開始您的旅程」、「了解產品」、「精通 AI」、「AI Fluency，為您的世界而生」和「使用 API 進行開發」幾個方向，對想有系統學習的人來說，比自己到處找文章更容易找到入口。

現在 Claude Academy 已經提供繁體中文版本，這件事很重要。學習新工具時，先用熟悉的語言理解整體地圖，可以大幅降低入門門檻；不用一開始就被英文介面、課程分類或專有名詞擋在門外。

當然，部分新課程目前還是英文。這沒有關係，反而可以把它當成另一種學習機會：先用繁體中文掌握概念，再接觸英文原文與最新術語。課程內容本來就會持續更新，能讀懂英文版本，也比較容易跟上後續新增的內容。中文化是讓更多人開始，而不是把學習的路線縮短。

所以這 30 天，我想跟著 Claude Academy 走一遍。這不會是把課程大綱逐段翻成中文的筆記，而是每一天讀完一段課程後，整理一個官方講到、但我覺得值得帶回工作裡的細節，再加上自己的實際案例。

## Day 1 - 序曲：為什麼要重新認識 Claude？

官方網站：[Claude Academy 課程總覽](https://academy.claude.com/zh-TW/courses)

Claude Academy 目前的課程分成五大分類：開始您的旅程、了解產品、精通 AI、AI Fluency 為您的世界而生，以及使用 API 進行開發。總共有 26 堂課，原本照課程數量直接切成 26 天就好，但有些課程內容很適合拆開，有些則是同一套框架換不同身分別重新講一次。

因此我會把該拆的拆開、該合的合起來，保留全部課程，但讓每天的主題比較適合閱讀。每篇文章固定回答四件事：這堂課教什麼、哪個細節容易被滑過去、我會怎麼用，以及最後留下一句評論或延伸想法。

## 開始您的旅程

### Day 2 - Claude 101

官方課程：[Claude 101](https://academy.claude.com/zh-TW/courses/claude-101)

從第一次對話、有效提示開始，一路看到 Projects、Artifacts、Skills、Connectors、Enterprise Search 與 Research，也會整理 Chat、Cowork、Code 的選擇邏輯，以及 Claude Code、Claude for Excel、Claude for Chrome 等周邊工具。

### Day 3 - Claude Code 101

官方課程：[Claude Code 101](https://academy.claude.com/zh-TW/courses/claude-code-101)

先建立 Claude Code 的基本使用方式，理解它和一般聊天視窗的差別，後面再把實戰、Skills、subagents 與工程流程拆開談。

### Day 4 - Claude Cowork 簡介（上）

官方課程：[Introduction to Claude Cowork](https://academy.claude.com/zh-TW/courses/introduction-to-claude-cowork)

認識 Cowork，並整理怎麼讓 Cowork 真的替自己工作。這會是日常案例最多的一天。

### Day 5 - Claude Cowork 簡介（下）

官方課程：[Introduction to Claude Cowork](https://academy.claude.com/zh-TW/courses/introduction-to-claude-cowork)

接著看 Chrome 與 Office 外掛、跨裝置使用、分享與安全，補上「會用」之外的工作邊界。

### Day 6 - Claude Platform 101

官方課程：[Claude Platform 101](https://academy.claude.com/zh-TW/courses/claude-platform-101)

把 Claude 產品與平台放回同一張地圖裡，理解一般使用者、團隊與開發者使用 Claude 時，彼此怎麼接起來。

## 了解產品

### Day 7 - Claude Code 實戰

官方課程：[Claude Code in Action](https://academy.claude.com/zh-TW/courses/claude-code-in-action)

從基本操作進入實際開發流程，對照我平常如何讓 Claude Code 讀專案、改 code 與驗證結果。

### Day 8 - Model Context Protocol 簡介

官方課程：[Introduction to Model Context Protocol](https://academy.claude.com/zh-TW/courses/introduction-to-model-context-protocol)

理解 MCP 想解決什麼問題，以及它如何讓 Claude 連上外部工具與資料。

### Day 9 - Model Context Protocol：進階主題

官方課程：[Model Context Protocol: Advanced Topics](https://academy.claude.com/zh-TW/courses/model-context-protocol-advanced-topics)

往權限、工具設計與實際整合再走一步，看看「接上工具」之後還有哪些工程問題。

### Day 10 - 子代理入門

官方課程：[Introduction to subagents](https://academy.claude.com/zh-TW/courses/introduction-to-subagents)

用自己的 subagent 案例對照官方課程，整理什麼工作適合拆出去，以及什麼時候拆了反而增加溝通成本。

### Day 11 - The AI-Native SDLC Playbook

官方課程：[The AI-Native SDLC Playbook](https://academy.claude.com/zh-TW/courses/ai-native-sdlc-playbook)

這堂新課談的是 AI 大量寫 code 之後，規劃、審查、測試與部署會變成新的瓶頸。會特別看 `intent.md`、`CLAUDE.md`、Skills、持續評測與 hooks 如何組成治理閉環，也會對照自己在權限管理與平台治理上的經驗。

### Day 12 - 代理技能簡介

官方課程：[Introduction to agent skills](https://academy.claude.com/zh-TW/courses/introduction-to-agent-skills)

把 Skill 當成可重複使用的工作方法，對照自己做過的 Skill，整理它和單次 prompt 的差別。

### Day 13 - Deploying Claude Enterprise with Confidence（上）

官方課程：[Deploying Claude Enterprise with Confidence](https://academy.claude.com/zh-TW/courses/deploying-claude-enterprise-with-confidence)

從 Structure & Identity、Access、Governance 三個面向開始，看看企業導入 Claude 時，哪些決策一開始就會影響後面能不能調整。

### Day 14 - Deploying Claude Enterprise with Confidence（下）

官方課程：[Deploying Claude Enterprise with Confidence](https://academy.claude.com/zh-TW/courses/deploying-claude-enterprise-with-confidence)

接著看 Spend、Visibility 與 work-along 實作，並對照自己做權限管理系統評估時的視角。

## 精通 AI

### Day 15 - AI 流暢度：Delegation

官方課程：[AI Fluency: Framework & Foundations](https://academy.claude.com/zh-TW/courses/ai-fluency-framework-foundations)

從 4D 框架的第一個 D——Delegation 開始，練習判斷什麼工作該交給 AI、什麼工作仍然需要自己掌握。

### Day 16 - AI 流暢度：Description、Discernment、Diligence

官方課程：[AI Fluency: Framework & Foundations](https://academy.claude.com/zh-TW/courses/ai-fluency-framework-foundations)

把 Description、Discernment、Diligence 三個 D 接起來，看清楚描述問題、判斷結果與持續修正，如何比「會不會下 prompt」更重要。

### Day 17 - AI 能力與限制：Next Token Prediction、Knowledge

官方課程：[AI Capabilities and Limitations](https://academy.claude.com/zh-TW/courses/ai-capabilities-and-limitations)

先理解模型如何生成下一個 token，以及它所謂的 knowledge 到底代表什麼。

### Day 18 - AI 能力與限制：Working Memory、Steerability

官方課程：[AI Capabilities and Limitations](https://academy.claude.com/zh-TW/courses/ai-capabilities-and-limitations)

再看 working memory 與 steerability，理解 Claude 為什麼有時候記得、有時候偏掉，以及我們可以怎麼把它拉回來。

### Day 19 - Building Effective Human Agent Teams

官方課程：[Building Effective Human Agent Teams](https://academy.claude.com/zh-TW/courses/building-effective-human-agent-teams)

這堂 Beta 課程很短，但剛好可以拿來對照自己正在使用的多代理系統：人和多個 Agent 到底要怎麼分工，才不會只是同時開很多視窗。

## 使用 API 進行開發

### Day 23 - 使用 Claude API：API 存取與提示工程

官方課程：[Building with the Claude API](https://academy.claude.com/zh-TW/courses/building-with-the-claude-api)

從 API 存取 Claude 與提示工程開始，這一天會實際申請 Anthropic API key，不只讀課程大綱。

### Day 24 - 使用 Claude API：工具使用與 RAG

官方課程：[Building with the Claude API](https://academy.claude.com/zh-TW/courses/building-with-the-claude-api)

實際跑過 Tool Use 與 RAG 範例，理解 Claude 如何使用工具，以及如何在外部資料加入後建立比較可靠的工作流程。

### Day 25 - 使用 Claude API：MCP、Claude Code、電腦使用與代理

官方課程：[Building with the Claude API](https://academy.claude.com/zh-TW/courses/building-with-the-claude-api)

把 MCP、Claude Code、computer use、代理與工作流程串在一起，整理從單次 API 呼叫走向完整 Agent workflow 時，新增了哪些設計問題。

### Day 26 - Claude 與 Amazon Bedrock

官方課程：[Claude with Amazon Bedrock](https://academy.claude.com/zh-TW/courses/claude-with-amazon-bedrock)

粗略看課程是相同所以主要也是差異比較，主要看 AWS 帳號、Bedrock 存取權限與 API 存取差異，再抽幾堂確認其餘內容只是換 SDK 或平台。

### Day 27 - 透過 Google Cloud 的 Vertex AI 使用 Claude

官方課程：[Claude with Google Cloud’s Vertex AI](https://academy.claude.com/zh-TW/courses/claude-with-google-cloud-s-vertex-ai)

粗略看課程是相同所以主要也是差異比較，集中看 GCP 帳號、Vertex AI 存取設定與 API 入口，讓讀者知道什麼時候平台差異真的值得處理。

## 緩衝與總結

### Day 28, 29 緩衝

目前是暫時規劃每日預訂要學習的課程進度，但實際上遇到課程內容比較精實或沒接觸過的地方在拆開說明會比較好。

### Day 30 - 系列總結：資源整理與學習路徑

最後一天不再介紹新課程，而是把 30 天走過的內容重新畫成學習路徑：如果你剛接觸 Claude，從哪裡開始；如果你已經在用 Claude Code，下一步該補什麼；如果你要做企業導入或 API 開發，又該把時間放在哪裡。

這就是這次鐵人賽的起點。以前我把 Claude 當成每天打開來工作的工具，這次想把它當成一門值得重新修一次的課。
