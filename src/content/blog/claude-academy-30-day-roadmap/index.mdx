我每天都在用 Claude：用它協助工作、在 Claude Code 裡一起改 code，也會讓 Cowork 處理一些日常任務。最近為了規劃鐵人賽，我重新打開 Anthropic 的課程平台，卻發現它已經從 Skilljar 改版成了 Claude Academy，還多了繁體中文介面與新課程。

那一刻我突然覺得，自己好像一直在使用 Claude，卻沒有好好重新認識它。熟悉工具的操作，不代表真的理解它的能力邊界；更不代表知道官方希望使用者建立什麼樣的工作方法。

其實 Claude Academy 一直都在那裡，我也知道它有一整套官方課程，只是一直沒有實際去看。每天都在用的工具，反而最容易變成「會用就好」的東西，認真學的機會就一直往後放。這次剛好藉著參加鐵人賽的機會，把挑選的 18 門課逐一走過，邊學邊整理成文章。寫成紀錄，一方面給自己留下學習的痕跡，另一方面也希望推廣給同樣每天在用 Claude、卻還沒好好學過的人。

## 先認識 Claude Academy

[Claude Academy](https://academy.claude.com/zh-TW/courses) 是 Anthropic 的官方教學網站，提供課程、短篇教學與使用案例，從第一次和 Claude 對話，一路延伸到 Claude Cowork、Claude Code、MCP、AI Fluency，以及使用 API 開發應用程式。課程頁面也把內容整理成「開始您的旅程」、「了解產品」、「精通 AI」、「AI Fluency，為您的世界而生」和「使用 API 進行開發」幾個方向，對想有系統學習的人來說，比自己到處找文章更容易找到入口。

現在 Claude Academy 已經提供繁體中文版本，這件事很重要。學習新工具時，先用熟悉的語言理解整體地圖，可以大幅降低入門門檻；不用一開始就被英文介面、課程分類或專有名詞擋在門外。

當然，部分新課程目前還是英文。這沒有關係，反而可以把它當成另一種學習機會：先用繁體中文掌握概念，再接觸英文原文與最新術語。課程內容本來就會持續更新，能讀懂英文版本，也比較容易跟上後續新增的內容。中文化是讓更多人開始，而不是把學習的路線縮短。

所以這 30 天，我想沿著這 18 門課的學習路線走一遍。這不會是把課程大綱逐段翻成中文的筆記，而是每一天讀完一段課程後，整理一個官方講到、但我覺得值得帶回工作裡的細節，再加上自己的實際案例。

下面每門課都附上官方課程連結、實際發布的 iThome 文章，以及 blog 上的對應版本。

## 小結

這就是這次鐵人賽的起點。以前我把 Claude 當成每天打開來工作的工具，會寫 prompt、丟檔案、請它改 code，但很少停下來想它到底能做什麼、官方怎麼建議使用，以及我有哪些地方其實一直用錯。這次把挑選的 18 門課走一遍，就是想把這些零散的使用經驗，接回官方的教學脈絡。

30 天的排程目前只是粗略排出來的。我先把課程依序分到每一天，其中有些課程看起來超過三小時，實際上課時可能要拆開，或是調整時間。等真正開始上課、看到每門課的內容密度之後，再依照課程內容修正時間，不急著把每天的安排定死。

每一篇文章我都會用同樣的方式寫：先講這堂課教什麼，再挑一兩個官方講了但容易被滑過去的細節，接著放進自己的工作案例裡，最後留一句評論或延伸想法。如果你只想快速看懂某一門課，直接看那一天的文章就好；如果想從頭照著走，這篇就是地圖。

這 30 天結束時，我希望留下的不只是一份筆記，而是一張重新整理過的 Claude 使用地圖：哪些事情適合交給它，哪些地方仍然需要自己判斷，哪些能力值得在團隊裡推廣。如果你在某一天讀到不同的看法，或是有自己用 Claude 的經驗，都歡迎告訴我。
